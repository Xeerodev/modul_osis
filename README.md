# Modul OSIS

Website pembelajaran interaktif untuk membantu pengurus OSIS memahami **Leadership** dan **Manajemen Organisasi**.

## Tentang Website

Modul ini dibuat sebagai media pembinaan OSIS dengan materi yang disusun sederhana, visual yang responsif, serta aktivitas yang dapat langsung digunakan oleh siswa.

Website ini merupakan bagian dari kegiatan:

**KKN Universitas Annuqayah Posko 49**  
**PP. Fathul Ulum, Poteran, Talango**

## Fitur

- Materi Leadership dengan fokus pada keteladanan dan kepemimpinan diri.
- Materi Manajemen Organisasi dengan fokus pada perencanaan, pembagian tugas, koordinasi, dan evaluasi.
- Card materi pada halaman awal yang dapat ditekan untuk membuka materi secara langsung.
- Accordion untuk membaca topik secara bertahap atau membuka seluruh topik sekaligus.
- Studi kasus, checklist, komitmen pribadi, dan alur pembelajaran.
- Kuis interaktif dengan skor dan penjelasan jawaban.
- Tampilan responsif untuk desktop, tablet, dan smartphone.
- Footer dengan informasi posko serta kredit **Developed by Xeerodev**.

## Cara Menjalankan

Website dibuat dalam satu file HTML sehingga tidak membutuhkan instalasi atau dependensi tambahan.

1. Buka file `index.html` di browser.
2. Tekan card materi Leadership atau Manajemen Organisasi.
3. Pelajari topik, kerjakan aktivitas, lalu selesaikan kuis.

Website ini juga dapat langsung digunakan untuk deployment di GitHub Pages atau Vercel.
